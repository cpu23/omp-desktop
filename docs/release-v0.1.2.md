# OMP Desktop v0.1.2

- Added a persisted **Max sessions** setting with saved/current limit status and a daemon restart control. Limits below the live session count are rejected to protect session restoration.
- Fixed restart ownership detection and session-capacity accounting while sessions are starting.
- Improved streaming scrollback rendering and terminal geometry during session replay and restoration.
- Added sidebar activity beside shimmering session titles and improved session-card interactions.
- Improved space rendering, configurable shortcuts, closable tabs and completion notifications.
- Fixed native clipboard paste.

Source release; no prebuilt installers. See the [desktop guide](guide.md) for setup and usage.
