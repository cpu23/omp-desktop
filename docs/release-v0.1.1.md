# OMP Desktop v0.1.1

- Added persistent spaces, cross-space session moves, and `Alt+1`–`Alt+9` space switching.
- Added configurable shortcut sequences and opt-in completion notifications.
- Improved WebGL resizing and terminal restoration; added native file drops and output replay when panes reopen.

Source release; no prebuilt installers. See the [desktop guide](guide.md) for current instructions.
