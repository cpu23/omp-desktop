Session limit

How many omp sessions the daemon may run at once (16 by default). The daemon owns this limit; a change that cannot apply to the running daemon needs a restart.

Restart to apply the saved limit. Restarting stops every running session: in-progress work and unsaved input are lost. Sessions with a saved transcript resume automatically afterwards; their running processes are not preserved.

Keyboard shortcuts

Use Ctrl, Meta, Alt, or Shift on the first key. Separate sequence presses with commas and alternatives with semicolons.
